# Personal Assistant

这是一个使用 Next.js App Router、TypeScript 和 Tailwind CSS 搭建的个人智能助手项目。

RAG 是该项目中的一个子模块，用于支持知识检索、上下文增强和问答能力；后续项目会继续增加更多智能助手能力。

## 开始使用

安装依赖：

```bash
npm install
```

启动开发服务器：

```bash
npm run dev
```

打开浏览器访问：

```text
http://localhost:3000
```

## 常用命令

```bash
npm run dev
npm run build
npm run start
npm run lint
```
